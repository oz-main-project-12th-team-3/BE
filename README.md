# TEAM 3 이십세

## 📖 프로젝트 소개 <img src="data:image/gif;base64,R0lGODlhAQABAIAAAP///wAAACH5BAEAAAAALAAAAAABAAEAAAICRAEAOw==" width=16px>`나만의 AI 비서`
>AI 비서 프로젝트는 사용자가 자연어로 대화하며 다양한 일상 업무를 관리할 수 있도록 도와주는 스마트 비서 애플리케이션입니다. 현재까지 구현된 주요 기능은 다음과 같습니다.

>AI 채팅: 사용자의 질문이나 요청에 대해 AI가 자연스러운 대화를 통해 응답합니다.

>일정 관리: 일정을 등록하고 수정할 수 있어, 개인 업무와 약속을 손쉽게 관리할 수 있습니다.

>알림 기능: 사용자의 일정이나 구독 정보 등 다양한 알림을 제공합니다

향후 계획으로는 일정 자동 추천, 다양한 생산성 도구 연동 등을 추가하여, 보다 똑똑한 개인 비서로 확장할 예정입니다.

## 📑 프로젝트 규칙
### Branch Strategy
> - dev 브랜치 기본 생성 
> - dev로 직접 push 제한
> - PR 전 팀장 승인 필수

### Git Convention
> 1. 적절한 커밋 접두사 작성
> 2. 커밋 메시지 내용 작성
> 3. 내용 뒤에 이슈 (#이슈 번호)와 같이 작성하여 이슈 연결

> | 접두사        | 설명                           |
> | ------------- | ------------------------------ |
> | Feat :     | 새로운 기능 구현               |
> | Feat :     | 새로운 기능 구현               |
> | Add :      | 에셋 파일 추가                 |
> | Fix :      | 버그 수정                      |
> | Docs :     | 문서 추가 및 수정              |
> | Style :    | 스타일링 작업                  |
> | Refactor : | 코드 리팩토링 (동작 변경 없음) |
> | Test :     | 테스트                         |
> | Deploy :   | 배포                           |
> | Conf :     | 빌드, 환경 설정                |
> | Chore :    | 기타 작업                      |

### Pull Request
> ### Title
> * 제목은 `#[이슈번호] Feat: 메인 페이지 구현` 과 같이 작성합니다.

> ### PR Type
  > - [ ] FEAT: 새로운 기능 구현
  > - [ ] ADD : 에셋 파일 추가
  > - [ ] FIX: 버그 수정
  > - [ ] DOCS: 문서 추가 및 수정
  > - [ ] STYLE: 포맷팅 변경
  > - [ ] REFACTOR: 코드 리팩토링
  > - [ ] TEST: 테스트 관련
  > - [ ] DEPLOY: 배포 관련
  > - [ ] CONF: 빌드, 환경 설정
  > - [ ] CHORE: 기타 작업
